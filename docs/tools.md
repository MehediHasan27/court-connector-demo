# Tool reference

Generated from the server's tool registry (`npm run submission`).


Classes follow Muse's rules: Read changes nothing; a tool that combines reads and writes is a Write; a Sensitive write is irreversible or consequential, and Muse asks "Allow once / Deny" on every call.

| Tool | Muse class | Side effects | Idempotent | Inputs | Errors |
|---|---|---|---|---|---|
| `check_availability` | Read | None for the caller. Reads slots, courts, the venue and the caller's own waitlist offer. Like every tool, it first releases waitlist holds whose offer has expired (housekeeping, not a change the caller asked for). | n/a (read-only) | `date` string, required: Date to check (YYYY-MM-DD)<br>`start_after` string, optional: Only show slots starting after this time (HH:MM, 24h)<br>`start_before` string, optional: Only show slots starting before this time (HH:MM, 24h)<br>`surface_type` string, optional: Filter by surface type (hard, clay, turf)<br>`indoor` boolean, optional: Filter by indoor/outdoor<br>`user_ref` string, optional: Optional player reference; if the player has a waitlist offer it is returned as pending_offer | Availability check failed: (database message) |
| `get_quote` | Write | Inserts one row in quotes (price locked until it expires). The slot stays available. | No | `slot_id` string (uuid), required: The slot ID to get a price quote for | Slot not found; Slot is not available; Failed to create quote |
| `create_booking` | Sensitive write | Redeems the quote, marks the slot booked, inserts one confirmed booking (all-or-nothing; of two concurrent bookings for one slot only one succeeds). For a waitlist offer, also marks the waitlist entry booked. No payment is taken. | Yes | `quote_id` string (uuid), required: The quote ID from get_quote<br>`idempotency_key` string, required: Unique key to prevent duplicate bookings<br>`user_ref` string, optional: Optional user reference | Quote not found; Quote already redeemed; Quote has expired; Quote integrity check failed; This quote is reserved for another player on the waitlist; Slot is no longer available; Failed to reserve slot; Failed to create booking |
| `modify_booking` | Write | Frees the original slot, books the new slot, updates the booking, and records a redeemed quote for the new slot (all-or-nothing). The freed slot may be held for the oldest matching waitlist entry, whose player is alerted. | No | `booking_id` string (uuid), required: The reservation ID to modify<br>`new_slot_id` string (uuid), required: The new slot to move the booking to | Booking not found; Booking is not active; New slot not found; New slot is not available; Failed to update booking |
| `cancel_booking` | Write | Sets the booking to cancelled and the slot back to available (both or neither). If a waitlist entry matches, the slot is held for the oldest one and that player is alerted. | Yes | `booking_id` string (uuid), required: The reservation ID to cancel | Booking not found; Booking is not active |
| `join_waitlist` | Write | Inserts one waitlist entry (date, window, filters, optional email/phone with the time of consent). No slot is held until a court frees up. A later offer holds one slot for the offer window and may send one email or text. | Yes | `date` string, required: Date the player wants a court (YYYY-MM-DD)<br>`start_after` string, optional: Earliest start time (HH:MM, 24h)<br>`start_before` string, optional: Latest start time (HH:MM, 24h)<br>`surface_type` string, optional: Only courts with this surface (hard, clay, turf)<br>`indoor` boolean, optional: Only indoor (true) or outdoor (false) courts<br>`user_ref` string, optional: Stable reference for the player; the offer is held for this user only<br>`email` string, optional: Optional email address for a slot alert<br>`phone` string, optional: Optional mobile number in international format, e.g. +14155550123, for a text alert<br>`consent` boolean, optional: Must be true if email or phone is given: the player agreed to be contacted about this waitlist entry | user_ref is required for the waitlist: pass a stable reference for the player so the offer is held for them only; Consent required: ask the player whether we may contact them at that email or phone about this waitlist entry, then call again with consent: true; email is not a valid address; phone must be in international format, e.g. +14155550123; date is in the past; start_after must not be later than start_before; N matching slots are available now: use check_availability and book one instead of joining the waitlist; Waitlist limit reached (10 active entries): leave one first; Waitlist is not available for this venue's booking system; Failed to join waitlist |
| `leave_waitlist` | Write | Sets the entry to left; releases its held slot, if any, which may be offered to the next waiting entry. | Yes | `entry_id` string (uuid), required: The waitlist entry ID from join_waitlist or get_waitlist_status<br>`user_ref` string, optional: Stable reference for the player who joined | user_ref is required for the waitlist: pass a stable reference for the player so the offer is held for them only; Waitlist entry not found |
| `get_waitlist_status` | Read | None for the caller. Reads the caller's own waitlist entries and offers. Like every tool, it first releases waitlist holds whose offer has expired. | n/a (read-only) | `user_ref` string, optional: Stable reference for the player whose waitlist entries to show | user_ref is required for the waitlist: pass a stable reference for the player so the offer is held for them only |

Every tool also carries MCP annotations (`readOnlyHint`, `destructiveHint`, `idempotentHint`, `openWorldHint: false`) and ends its description with its Muse permission class.
